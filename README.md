## Mock bank

`make bank` starts "Ironbridge Teller 7", the fictional legacy teller app Eagleview automates, as two
tenants: Lantern Bay FCU on http://127.0.0.1:8601 and Copperhill CCU on http://127.0.0.1:8602. Set
`IRONBRIDGE_TELLER_PASSWORD` in `.env` first (see `.env.example`); sign on as `teller01`.

All institutions, people, and data in this repository are fictional and synthetic.
